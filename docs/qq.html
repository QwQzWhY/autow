1 建一个访问令牌

手机要往你的 GitHub 仓库投递消息，需要一个令牌。去 Fine-grained tokens 新建一个：

  • Repository access：只勾选 这一个仓库
  • Permissions → Repository permissions → Contents 选 Read and write
  • 有效期建议 90 天

2 填仓库和令牌

只存在这台手机里，除了 api.github.com 不会发往任何地方。

3 配到手机上

  1. 应用商店装 MacroDroid，新建宏
  2. 触发器：通知 → 收到通知；应用选 QQ；内容包含 @全体成员
  3. 动作：网络 → HTTP 请求（POST），把下面四项照抄
  1. 手机浏览器打开 autow-bridge.apk，下载后安装 （需要允许「安装未知来源的应用」）
  2. 想自己编译：仓库的 Actions → 构建通知桥 APK → Run workflow
  3. 打开 App，把下面的仓库和令牌填进同样的两个框
  4. 点「① 开启通知使用权」，在系统设置里勾上它

4 测试

点一下，从这台手机发一条假消息给云端。收到就说明整条链路通了。

通知桥只读 QQ 弹出来的通知，不登录账号、不碰聊天记录。主号零风险。
默认只转发含 @全体成员 的消息；管理员发言要在 QQ 里把他们设成 「特别关注」才会弹通知。
